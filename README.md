# 경제 지표 대시보드

미국·한국 주요 경제 지표를 버튼 하나로 받아 와서 **직전 발표값과의 차이, 1년 추세, 최근 10년 중 위치**를 한 화면에 보여 주고, 정해 둔 기준에 따라 **주목할 점을 해설**하는 개인용 대시보드입니다. 구독 중인 시황 텔레그램 채널의 글을 규칙에 따라 정리한 **텔레그램 브리핑**도 함께 보여 줍니다.

## 만든 이유

시장 상황을 판단하려면 경제 지표 발표값, 금리·환율 같은 시장 가격, 그리고 시장이 왜 그렇게 움직였는지에 대한 해석을 함께 봐야 합니다. 하지만 이 정보들은 FRED, 한국은행, 증권사 채널 등 여러 곳에 흩어져 있습니다. 이 프로젝트는 흩어진 정보를 한 화면에 모으고, **숫자의 변화가 왜 중요한지**를 규칙 기반으로 짚어 주는 도구를 직접 만들어 보기 위해 시작했습니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 지표 업데이트 | 미국 13개, 한국 9개 지표를 FRED·한국은행 ECOS API로 받아 옴 |
| 직전 발표값 비교 | 최신값과 직전 발표값의 차이 표시 (정책금리는 마지막 변경 전 금리와 비교) |
| 1년 추세 | 최근 1년 자료에 직선을 맞춰 추세선과 1년간 변화폭 표시 |
| 역사적 위치 | 최신값이 최근 10년 자료 중 상위·하위 몇 %인지 표시 |
| 한미 금리차 | 기준금리차, 10년물 금리차(한국 − 미국)를 계산해 표시 |
| 규칙 기반 해설 | 물가 목표, 장단기 금리 역전, 삼 법칙, 변동성지수, 정책금리 변경, 이례적 변화, 추세 전환, 스태그플레이션 조합, 한미 금리차, 10년 최고·최저권 등 10가지 기준 |
| 새 발표 확인 | 반영하지 않은 새 발표가 몇 개인지 업데이트 버튼 아래에 표시 |
| 텔레그램 브리핑 | 시황 채널 글을 원인·반응·반대 재료, 특징 종목, 업종, 예상치 대비 언급으로 정리 |

### 다루는 지표
- **미국**: GDP 성장률, 소매판매, 산업생산, 소비자물가, 개인소비지출 물가, 연방기금금리, 국채 10년물 금리, 비농업 고용, 실업률, 신규 실업수당 청구, 변동성지수(VIX), 장단기 금리차(10년−2년), 달러지수
- **한국**: GDP 성장률, 수출액, 소비자물가, 한국은행 기준금리, 국고채 10년물 금리, 취업자 수, 실업률, 원/달러 환율, 코스피

## 설계에서 고민한 점

- **AI 대신 규칙 기반 해설**: 같은 숫자에는 항상 같은 해설이 나오고, 해설마다 근거 수치를 함께 보여 주도록 했습니다. 기준값은 `insights.py`의 `THRESHOLDS`에 모아 두어 직접 조정할 수 있습니다.
- **지표별로 "발표값"의 의미를 맞춤**: 물가는 전년 대비 상승률, 비농업 고용은 월간 증가폭, 정책금리는 마지막 변경 전 금리와 비교하는 식으로, 뉴스에서 실제로 보도되는 숫자에 맞췄습니다.
- **실제 채널 글을 보고 규칙을 고친 과정**: 처음에는 "낙폭 축소"를 하락으로, "하락 베팅 확대"를 상승으로 잘못 판단했습니다. 실제 글을 확인한 뒤 두 단어 표현을 먼저 판단하고, "A에 하락 후 B에 낙폭 축소"처럼 두 단계로 쓰인 흐름을 단계별로 나누도록 고쳤습니다.
- **무료 자료의 한계 대응**: FRED의 한국 자료 일부는 갱신이 중단되어 있어, 한국 지표는 한국은행 ECOS를 우선 사용하고 FRED를 대체 출처로 두었습니다. 출처 자료가 오래되면 "갱신 지연"으로 표시합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `server.py` | 대시보드 서버, 업데이트·새 발표 확인 기능 |
| `market_indicators.py` | 지표 목록, FRED·ECOS 데이터 수집, 계산 |
| `insights.py` | 규칙 기반 해설 |
| `telegram_brief.py` | 텔레그램 메시지 읽기와 규칙 기반 정리 |
| `telegram_login.py` | 텔레그램 첫 로그인(한 번만 실행) |
| `dashboard.html` | 대시보드 화면 |
| `대시보드 열기.bat` | 더블클릭으로 서버 실행 및 대시보드 열기(윈도우) |
| `문제 확인용 실행.bat` | 오류 내용을 창에 표시하며 실행 |

## 실행 방법

1. 패키지 설치
   ```
   pip install -r requirements.txt
   ```
2. `config.example.py`를 복사해 `config.py`로 이름을 바꾸고 API 키 입력
3. (선택) 텔레그램 브리핑을 쓰려면 터미널에서 한 번 로그인
   ```
   python telegram_login.py
   ```
4. `대시보드 열기.bat` 더블클릭 → 브라우저에서 **업데이트** 버튼 클릭

## 한계와 다음 계획

- 시장 예상치(컨센서스)는 무료로 받을 곳이 없어, 예상치 대비 서프라이즈는 텔레그램 글에 언급된 경우에만 보여 줍니다.
- 텔레그램 정리 규칙은 특정 시황 채널의 글 형식에 맞춰져 있어, 채널 형식이 바뀌면 규칙을 다시 맞춰야 합니다.
- 해설은 숫자 기준에 따른 참고 문구이며, 투자 판단의 근거로 쓰기 위한 것이 아닙니다.
- 다음 계획: 신용스프레드·금융 스트레스 지수 추가, 경기 국면 신호등 요약

- [한국은행 경제통계시스템 ECOS](https://ecos.bok.or.kr)
